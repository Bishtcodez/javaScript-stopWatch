# Interactive Stopwatch Web Application

A sleek, precise, and responsive web-based stopwatch application built using vanilla JavaScript, HTML5, and CSS3. 

## 🚀 Features
* **Precise Timing:** Accurate tracking of elapsed time including hours, minutes, seconds, and milliseconds.
* **Core Functionality:** Standard controls for Start, Pause, and Reset states.
* **Responsive Layout:** Designed with a clean, modern user interface that adapts seamlessly to both desktop and mobile screens.
* **State Management:** Controls dynamically enable and disable to prevent accidental double-clicks or bugs while the timer is running.

## 🛠️ Tech Stack
* **Structure:** HTML5
* **Styling:** CSS3 (Flexbox/Grid for layout alignment)
* **Logic:** JavaScript (ES6+ features, utilizing `setInterval` for timing accuracy)
